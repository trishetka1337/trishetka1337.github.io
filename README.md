# villcreat — живая визитка

Личная страница с живыми данными. Статика, без сборки и без бэкенда.

Часы, погода, положение солнца и орбиты спутников считаются прямо в браузере.
Всё, для чего нужны ключи или доступ к серверам, собирает GitHub Actions раз
в 30 минут и кладёт рядом готовый JSON. Секреты в репозиторий не попадают.

Часы показывают время автора. Погода, солнце и спутники считаются для города
посетителя. Город определяется сам по часовому поясу браузера: имя пояса и так
содержит крупный город, поэтому не нужны ни разрешение на геолокацию, ни сервисы
определения места по адресу. Из найденных совпадений берётся то, чей часовой
пояс совпадает с искомым, иначе поиск подсовывает однофамильцев: по запросу
New York находится деревня Йорк в Небраске.

Автоопределение не запоминается, чтобы город не прилип после переезда. Ручной
выбор в приоритете и сохраняется. Есть кнопка точного определения по геолокации:
она срабатывает только по клику, а координаты округляются до километра.

## Как посмотреть локально

Открывать `index.html` двойным кликом нельзя: браузер запретит модулям читать
`data/*.json`. Нужен локальный сервер:

```bash
python -m http.server 8000
```

Дальше http://localhost:8000

## Два языка

Сайт на русском и английском. Язык гостя определяется по браузеру, выбор
кнопкой RU/EN сохраняется и действует на всех страницах, включая блог.

Подписи интерфейса лежат в `assets/js/i18n.js`. Личные тексты в `config.js`
пишутся либо одной строкой (одинаково для обоих языков), либо парой:

```js
tagline: { ru: 'self-hosted всё подряд', en: 'self-hosting everything' },
```

## Блог

Заметки лежат в `posts/*.md`. В имени файла дата, тема и язык, например
`2026-09-10-perevyoz-servera.ru.md` и рядом `...en.md`. Файл без языка
в имени считается русским. Сверху шапка между тройками дефисов:

```markdown
---
title: Заголовок
date: 2026-09-10
tags: серверы, telegram
summary: Строка для списка и RSS. Если не писать, возьмётся начало текста.
draft: да
---

Текст заметки.
```

`draft: да` прячет заметку и с сайта, и из ленты.

Дальше `python scripts/blog.py` собирает страницы, списки и ленты для обоих
языков: `blog.html` и `blog.en.html`, `feed.xml` и `feed.en.xml`. В Actions это
происходит само при каждом пуше, локально запускается той же командой.

Если гость выбрал английский, а открыл русскую заметку, его перенесёт на
перевод. Когда перевода нет, заметка помечается «только на русском», и никуда
не перекидывает.

Страницы получаются обычной статикой: заметка читается с выключенным
JavaScript, а заголовок и описание попадают в разметку, а не подставляются
скриптом. Markdown разбирает свой маленький рендерер `scripts/markdown_mini.py`,
поэтому ставить ничего не нужно.

Адрес сайта для ссылок в ленте задаётся в начале `scripts/blog.py`,
переменная `SITE_URL`. Поменяй её, когда переедешь на свой домен.

## Фоновая музыка

Свой проигрыватель на своих файлах: кладёшь их в `assets/audio` или отдаёшь
со своего сервера и прописываешь в `config.js`, поле `player.tracks`:

```js
tracks: [
  { title: 'breakcore mix', artist: 'villcreat', src: 'assets/audio/mix.mp3' },
  { title: 'второй', src: 'https://твой-сервер/audio/second.mp3' },
],
```

Играет целиком, без чужих кадров и без чужих кук. Умеет паузу, перемотку,
громкость с запоминанием, список дорожек и повтор, если дорожка одна.
Файл не загружается, пока гость не нажал play.

Если своих файлов нет, но заполнено `player.link`, встраивается чужой
проигрыватель: YouTube и SoundCloud играют целиком, Spotify отдаёт гостям
только отрывки по тридцать секунд.

## Стена

Гостевая стена на отдельной странице `wall.html`. Записи хранятся в Supabase,
вход через Discord или GitHub. Пока ключи не вписаны, страница честно говорит,
что не подключена.

Как включить:

1. Завести проект на supabase.com, бесплатного тарифа хватит.
2. SQL Editor → выполнить `scripts/wall.sql`. Он создаёт таблицу и, что важнее,
   правила доступа.
3. Authentication → Providers → включить Discord и GitHub. Каждому нужно своё
   приложение: у Discord в Developer Portal, у GitHub в Settings → Developer
   settings → OAuth Apps. Redirect URL берётся прямо из панели Supabase.
4. Project Settings → API → скопировать Project URL и ключ `anon public`
   в `config.js`, поле `wall`.
5. Зайти на страницу стены, войти, посмотреть в консоли браузера свой
   идентификатор и вписать его в `ownerId`, а также в закомментированную
   политику в конце `wall.sql`. Это даст право убирать чужие записи.

Ключ `anon` публичный и лежит прямо в коде сайта, это нормально: доступ
ограничивают правила из `wall.sql`, а не секретность ключа. Поэтому не
поленись выполнить скрипт целиком.

Что уже защищено: длина записи ограничена в самой базе, писать можно только
от своего имени, не чаще одной записи в минуту с аккаунта, скрытые записи
не отдаются никому.

## Что где лежит

```
index.html              главная
posts/*.md              заметки блога, пишутся руками
blog.html, blog/, feed.xml  собираются скриптом, в репозитории не хранятся
assets/css/style.css    весь стиль, палитра в :root
assets/js/config.js     ник, город, ссылки, стек — правится руками
assets/js/main.js       сборка главной
assets/js/wall.js       стена
assets/js/i18n.js       строки интерфейса на двух языках
assets/js/sun.js        положение солнца, без внешних запросов
scripts/collect.py      сборщик живых данных, работает в Actions
scripts/wall.sql        таблица и правила доступа для стены
scripts/blog.py         сборщик блога
scripts/markdown_mini.py  разбор Markdown без зависимостей
data/*.json             результат сборщика, коммитить не обязательно
```

## Настройка

Всё личное живёт в `assets/js/config.js`: ник, подпись, часовой пояс, город по
умолчанию, главные проекты, контакты, кольцо сайтов.

Цвета меняются одной строкой в `assets/css/style.css`, переменная `--accent`.

## Секреты репозитория

Настройки → Secrets and variables → Actions. Все необязательные, без них
соответствующий блок просто не покажется.

| Секрет | Зачем |
|---|---|
| `GH_PAT` | Токен с правом `read:user`. Нужен для графа контрибуций, штатного токена Actions для него может не хватить |
| `LASTFM_USER` | Ник на last.fm |
| `LASTFM_KEY` | Ключ API last.fm, берётся на https://www.last.fm/api/account/create |
| `INFRA_TARGETS` | Список серверов для блока статуса, JSON одной строкой |

Ещё есть переменная (не секрет, вкладка Variables рядом):

| Переменная | Зачем |
|---|---|
| `SKIP_REPOS` | Имена репозиториев через запятую, которые не показывать в ленте |

Формат `INFRA_TARGETS`:

```json
[{"name":"gramsrv","host":"1.2.3.4","port":443,"role":"telegram"},{"name":"cloud","host":"1.2.3.5","port":443,"role":"nextcloud"}]
```

Наружу отдаются только имя, роль и время отклика. IP остаются в секретах.

## Включить Pages

Настройки → Pages → Source: GitHub Actions. Дальше деплой идёт сам при каждом
пуше и каждые 30 минут по расписанию.
