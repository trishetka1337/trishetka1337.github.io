## How to write

Put a file into the `posts` folder and name it by date, topic and language, for
example `2026-09-10-server-move.en.md`. The same post in Russian goes next to it
as `2026-09-10-server-move.ru.md`. Push it, and the pages and feeds build
themselves.

Normal markup works: **bold**, *italic*, ~~struck out~~, `inline code` and
[links](https://indieweb.org). Lists:

- bulleted
- like this

1. and numbered
2. too

A quote:

> Your own place on the web starts with your own domain.

A code block:

```bash
python scripts/blog.py
```

## What else

Add `draft: yes` to the header and the post stays off both the site and the
feed, which is handy while the text is unfinished.

If a post exists in one language only, its page says so and the language button
takes the reader to the post list instead.
