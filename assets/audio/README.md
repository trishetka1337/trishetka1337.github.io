Сюда кладутся свои аудиофайлы для проигрывателя на главной.

После этого пропиши их в `assets/js/config.js`, поле `player.tracks`:

```js
tracks: [
  { title: 'breakcore mix', artist: 'villcreat', src: 'assets/audio/mix.mp3' },
],
```

Про размер: в репозитории GitHub один файл не может быть больше 100 МБ,
а весь репозиторий рекомендуется держать меньше гигабайта. Часовой микс
в mp3 весит около 60-80 МБ, то есть влезет, но репозиторий раздуется
навсегда: git хранит все версии файла, и удалить его потом можно только
переписав историю.

Поэтому длинные записи лучше отдавать со своего сервера, а в src писать
полный адрес: `https://твой-сервер/audio/mix.mp3`. Проигрыватель это умеет,
никакой настройки не нужно.
